 # 📋 Stable Diffusion 漫画生成计划

 **模型**：meinaunreal_v5（动漫特化模型）
 **基础设置**：Steps 15-18 | CFG 6-7 | Sampler: DPM++ 2M | 尺寸 512×512
 **注**：CPU出图每张约1-3分钟，以下策略目标是**最小化生成次数，最大化命中率**

 ---

 ## 阶段一：🎯 角色定妆（最重要的一步）

 在生成任何漫画图之前，先把4个角色的"脸"定下来。每个角色只需要1-2次成功生成。

 ### 1.1 生成小粉（半身特写）

 ## 阶段二：🔑 用"种子+ControlNet"生成各场景

 定好角色脸之后，每个场景的生成思路：

 | 场景 | 方法 | 关键参数 |
 |------|------|----------|
 | 毕业 | txt2img直接生成（2人） | seed用小粉和花花的折中+多跑 |
 | 高铁内 | txt2img生成车厢背景+后期合成角色 | 角色面部不够好就只当素材 |
 | A市城市 | txt2img生成城市空镜 | 不需要角色，最好出 |
 | 姐姐家小房子 | txt2img画小房子外景 | 纯背景 |
 | 吃粽子 | 小粉+花花的种子+改场景词 | ControlNet固定坐姿 |
 | 找房子/奶奶引路 | 3人同框（小粉+花花+奶奶） | ControlNet openpose |
 | 看房子 | 同上 + 室内背景 | 后期合成 |
 | 打扫卫生 | 小粉+花花 | add detail词 |
 | 天黑睡着 | 睡觉特写+窗外夜景空镜 | 容易出，节省时间 |

 ### 关键技巧：后期合成

 由于CPU出图慢，**强烈建议**：
 1. 角色单独生成（512×768半身或全身）
 2. 空背景单独生成（512×512）
 3. 用画图软件裁剪✓合成（做最简单的人物抠图+叠加）

 这样一张图最多2次生成（人物1次+背景1次），比"人物+背景一次出"成功率高得多

 ---

 ## 阶段三：🎨 漫画化处理

 生成好的素材图 → 用图片编辑软件：
 1. 裁剪成漫画格尺寸
 2. 加对话框
 3. 加文字（中文）
 4. 调整明暗对比（漫画风格需要高对比）
 5. 排成漫画页（建议4-6格一页）
