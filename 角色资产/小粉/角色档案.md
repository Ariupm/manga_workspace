# 小粉角色档案

## 基本身份

- 角色 ID：`character_xiaofen`
- 中文名：小粉
- 角色类型：成年女性主角
- 默认定位：现代都市日常、职场、治愈与成长题材
- 标准参考图：`00-原始参考图.png`
- 标准模型图：`01-标准三视图.png`
- 表情参考图：`02-表情设定.png`

## 不可变化的外形特征

- 腰部长度的层次感粉色长发。
- 空气感斜刘海，两侧保留长脸侧发束。
- 暖粉棕色眼睛，带少量琥珀色高光。
- 柔和椭圆脸型，肤色白皙，脸颊有自然红晕。
- 成年女性的纤细、健康身体比例，不使用儿童或 Q 版身体比例。
- 整体气质温柔、安静、亲切，但不是软弱或幼态。
- 日间造型默认佩戴浅色颈带与金色小圆环。

## 标志色

- 发色：柔和樱粉
- 瞳色：暖粉棕
- 主服装色：米白、樱粉、藕粉
- 辅助色：灰蓝、藏蓝、浅灰
- 鞋包色：暖棕、玫瑰米色、奶油白

## 生成约束

1. 每次生成小粉前，至少引用标准模型图和本次服装所在的衣橱设定图。
2. 同一场景连续镜头必须保持发型、服装、鞋子、包和配饰一致。
3. 同一天的室外剧情不得自动更换工作装或休闲装。
4. 进入家中后应脱掉室外鞋；换睡衣后只能搭配居家拖鞋或赤脚。
5. 除非剧情明确要求，不改变发色、瞳色、头发长度、刘海、脸型和年龄感。
6. 画面内不直接生成对白文字；对白和气泡在漫画排版阶段添加。

- 未指定的夏季休闲剧情：`XF-CASUAL-01` + `XF-SHOE-10`。
