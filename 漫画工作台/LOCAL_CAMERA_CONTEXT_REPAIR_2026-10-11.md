# 局部镜头上下文修复与图像对照

本轮按用户最新要求进行了真实 SD 图像对照；程序检查与图像观察分别记录。关联 `ISSUE-PROMPT-019`。没有把低头等同于工具操作成功，也没有从单个样本推断所有动作都会改善。

## 三类退化原因的核实

| 待验证原因 | 当前证据与结论 |
|---|---|
| 外观、画风或重复文字弱化动作 | 历史长短文本实验存在差异，但方向、外观、控制和种子因素尚未完全分离。当前五动作编译快照仍保留原动作、低头和左右手文字，不能把失败简单归因为动作被截断。此次没有全局缩短或删除外观。 |
| 手、工具、目标关系被改错 | 017/018 已有程序复现与修复；017 四组真实配对没有明确动作改善。此次不把这些已修复的程序错误再次称为视觉问题的充分解释。 |
| 后续阶段覆盖或混入无关上下文 | 019 确认：公共 `cameraAngle` 的 `looking down at the book` 原样进入服装局部请求，也可能广播给其他人物的局部阶段。历史配对中衣内额外书本消失，颜色仍失败；本轮通过正式编译器重新准备两种子配对。身份接续历史样本保持低头，不能认定所有身份精修都会破坏动作。 |

## 修复范围

新任务的事实快照保存 `local-camera-context-1`。局部编译仅对镜头字段中有明确语法边界的 `looking/gazing … at/toward …` 子句作投影：保留光学角度，去掉该公共目标。没有人物绑定的公共目标不再作为局部编辑对象；人物自身的视线、工具及工作目标仍从本人事实读取。

基础请求保留完整原始镜头描述。人物动作、手侧、衣服图案和遮挡不做全局关键词删除。模糊主体句和无法判定的镜头文字保持原文，未知否定仍走原编译错误规则。移除的原文、保留文本和原因进入实际请求审计。

新版本由前台/API 共用的 `buildRegionalPrompt` 写入，经 `buildEffectivePromptPlan`、关系重绑、最终编译和 recipe 指纹保存。旧任务缺少该版本时保持原请求行为；本轮只在独立实验克隆中显式加入新版本，未重写 job561/563 等已存任务。

## 完整业务链冲突复核

| 节点 | 复核结果 |
|---|---|
| 剧情/人工选择 → 视觉规格 | 输入与确认状态不改。本人视线和手物关系仍为来源；不从公共镜头推断新动作。 |
| 提示词/交互契约 | 只改变有新版本的局部 `cameraAngle` 投影。动作/手/工具目标/阶段、衣物图案、本人遮挡及照明保留；测试包含两个不同视线的人物及不同区域。 |
| recipe/payload | 版本随关系重绑、有效 Pose 编译和最终指纹保存；实际请求适配器输出审计。旧版本结果保持，错误指纹仍拒绝。 |
| Regional/ControlNet → 基础生成 | 基础 prompt 不变；人数、近/中/远景、多人物 Regional、骨架开关、参考控制参数和 mask 不改。 |
| 身份/服装/道具/手部/视线/交接 | 六阶段只收敛公共镜头上下文。本人视线不受影响；工具及工作对象保持原关系链。五动作×六阶段共30份不含目标子句的历史编译结果逐项完全一致。 |
| 失败/质量处理 → 草稿整体确认 | 未改变任何阻断、降级或审批规则；既有技术失败处理保留，未增加逐项人工语义操作或自动视觉检测。 |
| 正式候选回写 | 沿用现有 worker 策略与状态，不把实验图自动入候选，不伪造已应用或视觉通过。旧用户草稿保持等待确认。 |

检查中未发现由本次改动引起的控制或状态机冲突。完整前台视觉稳定性仍未验收；本轮实际请求只验证服装局部阶段。人工服装 mask、混色、精确工具接触、参考与 Pose 的模型层竞争均不能由这项修复宣布解决。
