# 小粉漫画制作台

本地优先的 AI 漫画制作工作台 MVP。

> 新对话或新开发者接手时，请先阅读 [`PROJECT_MEMORY.md`](./PROJECT_MEMORY.md)。该文件记录当前架构、生成参数、已知缺陷和下一步优先级。

## 启动

```powershell
pnpm install
pnpm dev
```

打开终端显示的本地地址。首次访问会自动创建 SQLite 数据库和“小粉求职记”示例项目。

## 图片生成

当前内置 Stable Diffusion WebUI 适配器。复制 `.env.example` 为 `.env.local`：

```env
IMAGE_PROVIDER=sd-webui
SD_WEBUI_URL=http://127.0.0.1:7860
```

使用 `--api` 启动 Stable Diffusion WebUI 后，单格工作台的“生成候选”会调用 `/sdapi/v1/txt2img`。设置页会分别显示配置、地址、API、ControlNet 和 IP-Adapter 检测结果。修改 `.env.local` 后必须重启工作台。

生图提示词只使用英文视觉字段，对白不会提交给图片模型。

## DeepSeek 剧情视觉规划

“生成设置”可启用 DeepSeek 全章视觉规划与单镜头细化。API Key 由服务端使用 Windows 当前用户级 DPAPI 加密保存，浏览器、日志与生成任务均不会获得明文。默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-v4-pro`；未配置或调用失败时自动保留原有本地规则提示词流程。

DeepSeek 只接收剧情文字、角色 ID 和结构化资产描述，不上传角色图片。AI 输出先经过 ID 白名单与结构校验，用户确认后才参与 Stable Diffusion 提示词编译。

## Codex 生图队列

在单格工作台点击“Codex 当前页队列”，会为当前页每格写入英文提示词、负面提示词、两个候选的要求和角色参考图。然后在 Codex 对话中要求“处理当前页生图队列”。

没有配置生成服务时，可以复制完整正向/负向提示词到其他图片工具，再通过“导入候选图”保存版本。

## 已实现

- 项目首页与生产状态总览
- 剧情输入及无 API 本地规则分析
- 剧集制作流水线
- SQLite 项目、剧集、页面、分格、候选版本、资产与时间线模型
- 小粉角色、服装和鞋履资产匹配
- 独立作品与连载新章节分流
- 每章 5～7 张漫画页，每页按剧情生成 6～8 格
- 漫画页与分格切换
- 单格编辑、锁定、候选切换与独立重新生成
- 全英文生图提示词与中文校验
- 表情、动作、镜头、服装的局部修改面板
- 对白、旁白和拟声词独立图层，支持位置、尺寸、字号、旋转、复制、隐藏和删除
- 页面比例、分格模板、间距和边距的 SQLite 持久化
- 小粉资产清单自动导入（22项）
- 新人物草稿向导与英文视觉约束
- 整页漫画预览
- PNG 与 PDF 导出
- 长篇时间线及连续性检查

## 数据位置

- SQLite：`data/studio.db`
- 导出目录：浏览器默认下载目录
- 原始参考图片继续保存在上级漫画项目目录，工作台只读引用。
